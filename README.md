## Project Overview

Smart Retail Analytics System is an end-to-end computer vision application built with Ultralytics YOLO.

The project applies YOLO-based computer vision to a real-world retail video scenario. The system performs object detection, video analytics, and model evaluation.

## Technologies

- Python
- Ultralytics YOLO
- OpenCV
- NumPy
- Pandas
- Google Colab
- GitHub

## Core Deliverables

### 1. Core Vision Tasks & Inference

A pretrained YOLO model was loaded using the Ultralytics Python API and used for real inference.

The inference pipeline processed an input video frame and captured the resulting output.

### 2. Real-World Solution & Video Analytics

The YOLO model was applied to a real video-processing pipeline using OpenCV and Ultralytics Solutions.

The pipeline captures video frames, processes them, and generates analytics results.

### 3. Model Evaluation

The pretrained YOLO model was evaluated using the Ultralytics validation API and the COCO8 validation dataset.

The validation run produced the following results:

| Metric | Result |
|---|---:|
| Precision | 0.849 |
| Recall | 0.654 |
| mAP50 | 0.906 |
| mAP50-95 | 0.665 |

These results provide a quantitative baseline for the pretrained model.
